# Security and privacy

Do not include customer records, private support tickets, login details, API keys, browser storage, contact information, or identifiable user profiles in public issues or pull requests.

For a suspected vulnerability or privacy issue, open a GitHub private vulnerability report if available; otherwise open an issue containing only a non-sensitive description and ask the maintainer for a private follow-up route. Do not publish a live secret to demonstrate a problem.

The Skill itself is instruction-only and makes no network calls. Online collection is performed by the host agent only when authorized for the specific source.
