## 複数チャネルの行動ペルソナ研究

`multi-channel-persona-research`

許可された根拠、行動群、盲検案比較、実 A/B 計画をつなぎ、模擬選好を実結果と扱いません。

スキルディレクトリ: `.`

**実装の根拠と依存関係**

明確な判断と対象、読める許可資料が必要。複数チャネル結論には独立した出典種類が二つ以上。ブラウザ・分析・実験基盤は条件付きです。

**入力**

必須 decision_question、target_scope、日付/権限付き evidence_sources。任意：比較案、基準、標本枠、費用/安全条件、期間。第一者資料は最小限に処理します。

**出力**

persona-research.md：出典台帳、証拠 ID/符号化/矛盾、行動群、群別比較、実験要約。群比率不明では全体勝率を出しません。

[実行手順 · 制約と停止条件 · 依頼例](references/i18n/ja.md)

> 次のスキルを使用してください： `$multi-channel-persona-research` — フォーラムと許可されたサポート資料で予約画面二案を盲検比較し、改善率を断言せず無作為テストを設計します。日本語で回答し、根拠、不明点、操作権限を維持してください。
