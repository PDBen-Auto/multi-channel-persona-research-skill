사용자가 명시한 출력 언어를 따르고, 지정이 없으면 요청 언어를 따릅니다. 명령, 스킬 ID, JSON 키, 열거값, 단위와 원문 인용은 유지합니다. 번역과 원문을 구분하고 언어로 국가, 통화, 관할을 추정하지 않습니다. 전체 명세의 관련 자료를 읽고 기존 검증과 권한 조건을 적용합니다.

## 설치와 사용

저장소를 내려받거나 복제한 뒤 아래 스킬 디렉터리를 기존 references, scripts, assets 등과 함께 호스트의 스킬 디렉터리에 복사합니다. 이름과 SKILL.md는 유지합니다. 문서 언어만 바꾸는 경우 재설치할 필요가 없습니다. 설치 명령은 선택지이며 설치 또는 활성화 완료를 뜻하지 않습니다.

```sh
git clone https://github.com/PDBen-Auto/multi-channel-persona-research-skill.git
```

## 다채널 행동 페르소나 연구

`multi-channel-persona-research`

승인 근거·행동 집단·블라인드 대안 비교·실제 A/B 계획을 연결하며 모의 선호를 실험 결과로 취급하지 않습니다.

스킬 디렉터리: `.`

**구현 근거와 의존성**

명확한 결정·대상과 읽을 수 있는 허가 자료가 필요합니다. 다채널 결론은 독립적인 출처 유형 두 가지 이상이 필요합니다. 브라우저·분석·실험 플랫폼은 조건부입니다.

**입력**

필수 decision_question, target_scope, 날짜·권한 있는 evidence_sources. 선택 비교안·기준·표본 틀·비용/안전·기간. 자사 자료는 허가 범위에서 최소 처리합니다.

**출력**

persona-research.md: 출처 기록, 근거 ID/코딩/충돌, 행동 집단, 집단별 비교, 시험 계획. 집단 비율을 모르면 전체 승률을 계산하지 않습니다.

[실행 절차 · 제약과 중단 조건 · 요청 예시](references/i18n/ko.md)

> 다음 스킬을 사용하세요: `$multi-channel-persona-research` — 포럼과 허가된 상담 근거로 예약 페이지 두 개를 블라인드 비교하고 전환 향상 주장 대신 무작위 실험을 설계합니다. 한국어로 답하고 근거, 미확인 사항과 작업 권한을 유지하세요.

## 언어 지원과 검증

이 문서는 목적, 전제, 입출력, 절차, 예시와 제약을 다루는 한국어 운영 가이드이며 모든 참고 문서의 문장별 번역은 아닙니다. 상세 기술 자료, 과거 사례, 스크립트 오류, 예제 화면과 이미지는 원래 언어를 유지합니다. 요청 시 해당 언어로 설명할 수 있습니다. 구조, 링크와 핵심 제약을 확인했으나 각 언어 원어민 교정은 수행하지 않았습니다.

전달 전에 입력, 근거, 결측값, 출력 파일과 원래 완료 기준을 대조합니다. 실행하지 않은 단계는 미검증으로 표시하며 스크립트의 정상 종료를 업무 검증 성공으로 취급하지 않습니다.
