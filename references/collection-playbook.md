# 渠道采集与画像维度手册

仅在需要执行采集、设计采样或校准画像字段时读取。本方法通过**互补渠道的行为线索交叉核对**降低单一渠道偏差，并不能让便利样本自动变成有代表性的调查样本。

## 1. 低成本采集顺序

1. 先用已有、获准的第一方资料：客服主题、退货/取消原因、站内搜索、操作漏斗、匿名化工单。它们最贴近实际任务，但只覆盖现有触达用户。
2. 再用公开的评论和问答找购买前疑虑、使用后落差与替代方案；用论坛/社区找完整场景和更长的使用周期。不要只抓高赞、差评或首页热门内容。
3. 需要理解表达、展示方式或信息偏好时，再看社交内容；需要理解需求词和发现路径时，再看搜索/站内行为。后两类线索通常不能独立证明购买或使用。
4. 每轮先筛标题/摘要/页面资格，再深读少量高信息量记录；先做小批编码，检查是否出现新维度和冲突，再决定是否扩展。优先填补决策关键证据空白，不为了凑人数继续采集。

## 2. 各渠道能回答的问题

| 来源类型 | 观察单位与应记录内容 | 主要能回答 | 常见盲点 |
|---|---|---|---|
| 第一方行为日志 | 匿名账号/会话、事件、时间、入口和后续行动 | 用户实际在哪一步停止或继续 | 行为原因不直接可见；埋点缺失与机器人流量 |
| 客服/售后 | 脱敏问题事件、处理结果、发生阶段 | 操作障碍、失败后果和信任问题 | 求助者偏差；同一问题可能重复工单 |
| 商品/应用评价 | 评价内容、版本/时间、使用阶段 | 实际体验、满意缺口、复购/替换信号 | 极端体验、平台激励、真实性和版本漂移 |
| 问答/比较页 | 具体问题、答案、时间 | 购买前不确定性和所需证明 | 提问不代表最终行动；回答者可能是商家 |
| 论坛/专业社区 | 帖子脉络、使用情境、回应、更新 | 任务、替代方法、长期权衡 | 活跃发言者偏差；同一人在多帖重复 |
| 社交内容 | 自述、展示行为、评论互动 | 语言、形象和内容表达偏好 | 展示性动机强；点赞不等于需求或购买 |
| 搜索/站内查询 | 查询词、入口、时间与后续行为 | 发现路径和短期意图线索 | 查询词含义多解；无后续行为时不证明需求强度 |

真实项目中的来源链接/内部记录 ID、内容日期、采集日期、授权与版本信息应留在内部证据表。若公开分享报告，使用不指向自然人的脱敏摘要；必要原文短引须确认使用权限。

## 3. 筛选、去重与偏差

- **资格筛选：**先确认发言者/行为单元与目标任务有关系。商家、代发、机器人、转述、图片无法确认的身份不纳入“真实使用者”计数；可另记为市场背景。
- **独立性：**一人多帖、同一工单多次跟进、同一评论被转发，都只算一个独立人/事件来源。跨平台不要凭用户名、头像或相似叙述认定同一人；未能确认时保留重复风险并避免加总独立人数。
- **冲突：**同一行为可能由价格、权限顾虑或时间不足引起。至少记录一个替代解释；出现相反证据时并列呈现。
- **覆盖：**把渠道、时间、使用阶段与目标人群列成交叉表。某个单元无资料是 `unknown`，不是需求不存在。
- **停止：**当继续采集不能改变待决方案、关键证据仍只能靠直接访谈/真实实验获得，或访问权限不足时，停止扩量并交付缺口。不要设置通用“采够 N 人即代表市场”的阈值。

## 4. 画像维度及证据锚点

| 维度 | 具体问题 | 可接受证据 | 不可直接推断 |
|---|---|---|---|
| 任务与目标 | 用户要完成什么、成功是什么 | 自述任务、实际流程、求助主题 | 看到页面就认定有购买目标 |
| 触发与场景 | 在什么条件下开始寻找方案 | 时间线、环境、明确事件 | 由职业或人口标签猜场景 |
| 当前做法 | 现用什么、为什么仍沿用 | 明确的替代工具、绕行行为 | 竞品广告即现有使用 |
| 痛点与后果 | 哪一步不顺、成本是什么 | 失败、返工、投诉、放弃 | 单次负评等于普遍严重问题 |
| 使用阶段/频率 | 初次、重复、升级或流失 | 带日期的重复行为、使用叙述 | 发帖次数等于实际使用频率 |
| 选择标准 | 在哪些收益间权衡 | 比较原话、实际筛选/放弃行为 | 点赞等于愿付价格 |
| 采用阻碍 | 权限、学习、安装、信任、费用 | 明确拒绝、失败事件、疑虑原话 | 无行动等于缺乏兴趣 |
| 证明需求 | 什么证据能让其放心 | 索要演示、规格、评价、试用 | “想看”即最后一定采用 |
| 行动承诺 | 是否完成试用、预约、付费等 | 可验证的实际行为 | 情绪表达等于转化概率 |

所有维度都保留 `direct`（明确自述）、`observed`（可见行为）、`inferred`（有替代解释的推断）、`unknown`、`conflict`。只在能说明行为差异时增加行业字段，例如 B2B 的决策角色、实体产品的安装条件或服务的交付时效；不要把示例行业字段做成通用必填项。
